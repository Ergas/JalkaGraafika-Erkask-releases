# JalkaGraafika ErKask

Windows desktop application for controlling football livestream graphics in vMix.

## Download

Download the latest Windows installer from the [Releases](https://github.com/Ergas/JalkaGraafika-Erkask-releases/releases) page:

- `JalkaGraafika ErKask Setup <version>.exe`

Run the installer and start **JalkaGraafika ErKask** from the Windows Start menu or desktop shortcut.

## Requirements

- Windows 10 or newer
- vMix with the Web Controller/API enabled
- Network access to the configured football match data source
- A valid application license for production livestream features

## vMix setup

1. Open vMix.
2. Enable the vMix Web Controller/API.
3. Confirm that the API is available on the configured host and port, normally port `8088`.
4. Open **vMix Settings** in JalkaGraafika ErKask and enter the vMix host and port.
5. Load a match and use the preview or live controls to send graphics to vMix.

## Updating

The application checks for new releases automatically when it starts. When an update is available, it downloads in the background and installs the next time the application exits.

You can also download the newest installer manually from the Releases page.

## Data storage

Match data and application settings are stored locally on the Windows computer. Uninstalling the application may not remove saved application data.
